# Electric Vehicle Analytics Dashboard
Created an interactive Electric Vehicle Analytics Dashboard in Microsoft Excel to analyze  vehicle performance
and business metrics. Cleaned and transformed raw data to ensure data accuracy and consistency before analysis.

# Key Resposibilites

• Analyzed Electric Vehicle (EV) data using Microsoft Excel.

• Cleaned and organized raw EV datasets for accurate analysis
  
• Created an interactive Excel dashboard using Pivot Tables and Charts.  

• Developed KPI cards for Total Vehicles, Insurance Cost, Battery Health, Average Range (KM), and Charging Cost.
  
• Analyzed key EV performance metrics to identify useful insights.
  
• Used charts and visualizations to present data effectively.
  
• Designed a user-friendly dashboard for better data understanding.
